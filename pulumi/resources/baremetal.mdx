---
title: "NEO Metal (Pulumi)"
description: "Pulumi resources and functions for NEO Metal bare-metal servers"
---

NEO Metal dedicated servers (`/baremetals` API group) plus their add-ons: additional (floating) IPs and NEO Elastic Storage.

<Info>
  Every create/upgrade places a **real paid order**. Read the [billing guide](/guides/billing) for `cycle` values and `payWithCreditCard` semantics.
</Info>

## `biznetgio:index:Baremetal`

    package main

    import (
        biznetgio "github.com/shirasakaren/pulumi-biznetgio/sdk/go/pulumi-biznetgio"

            })
            if err != nil {
                return err
            }

            server, err := biznetgio.NewBaremetal(ctx, "metal-main", &biznetgio.BaremetalArgs{
                ProductId:  pulumi.Int(products.Products[0].ProductId),
                Cycle:      pulumi.String("m"),
                SelectOs:   pulumi.String("ubuntu-22"),
                KeypairId:  keypair.KeypairId,
                Label:      pulumi.String("neo-metal-main"),
                PublicIp:   pulumi.Int(1),
                // PowerState:   pulumi.String("off"),
                // ResetTrigger: pulumi.String("reboot-1"),
                // RebuildOs:    pulumi.String("centos7-base"),
            })
            if err != nil {
                return err
            }

            ctx.Export("serverStatus", server.Status)
            return nil
        })
    }

                    .cycle("m")
                    .selectOs("ubuntu-22")

                    .label("neo-metal-main")
                    .publicIp(1)
                    // .powerState("off")
                    // .resetTrigger("reboot-1")
                    // .rebuildOs("centos7-base")
                    .build());

            ctx.export("serverStatus", server.status());
        }
    }

| Input | Type | Required | Notes |
| --- | --- | --- | --- |
| `productId` | int64 | yes | from `baremetalProducts` |
| `cycle` | string | yes | `m` monthly / `a` annual |
| `selectOs` | string | no | default `ubuntu-22`; create-only |
| `keypairId` | int64 | yes | from `BaremetalKeypair`; create-only |
| `label` | string | yes | display name - the only updatable input |
| `publicIp` | int64 | no | default `1`; create-only |
| `promocode` | string | no | create-only |
| `payWithCreditCard` | bool | no | default `true` |
| `powerState` | string | no | `on` / `off`; API called only on change |
| `resetTrigger` | string | no | one-shot reset; change value to re-fire |
| `rebuildOs` | string | no | destructive rebuild; valid values from `baremetalRebuildOsList` |

Outputs: `status`, `orderId`, `ipAddress`, `createdAt`, `raw` (secret, redacted). Import with the numeric account id.

## Functions

### `biznetgio:index:baremetalProducts`

No arguments. Returns `products`: `productId`, `name`, `description`, `raw` (secret).

### `biznetgio:index:baremetalRebuildOsList`

Argument `accountId` (int64). Returns `oss` (string[]) and `raw` (secret) - valid values for `rebuildOs`.

### `biznetgio:index:baremetalOpenvpn`

No arguments. Returns `config` (secret) and `raw` (secret) - out-of-band OpenVPN access configuration.
