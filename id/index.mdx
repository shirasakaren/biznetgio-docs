Biznet GIO itu cloud provider Indonesia yang punya VPS (NEO Lite), server bare-metal (NEO Metal), instance GPU (NEO GPU), dan object storage yang S3-compatible (NEO Object Storage).

<Warning>
  **Proyek komunitas, bukan official.** Provider dan dokumentasi ini dibangun oleh [Shirasaka Ren](/id/about) dan **tidak terafiliasi atau diendorse oleh PT Biznet Gio Nusantara** - Biznet GIO dan NEO adalah trademark masing-masing owner. Pakai dengan risiko sendiri; setiap create/upgrade bikin order berbayar beneran di akun lu.
</Warning>

Situs ini dokumentasiin dua provider Infrastructure-as-Code yang ngewrap [Biznet GIO Portal API](https://api.portal.biznetgio.com/v1/docs):

- **Terraform** - provider `biznetgio` (`registry.terraform.io/shirasakaren/biznetgio`), protocol 6.0 (Plugin Framework), butuh Terraform ≥ 1.0
- **Pulumi** - provider `biznetgio` (native Go, `pulumi-go-provider`), SDK buat TypeScript, Python, Go, .NET, dan Java

Dua-duanya share API surface yang sama, model authentication yang sama, dan semantics yang sama - tinggal pilih tools yang lu udah biasa.

<Info>
  **Baru banget di dunia ini?** Mulai dari [Infrastructure as Code tuh apa?](/id/what-is-iac), penjelasan IaC, Terraform, dan Pulumi dari nol.
</Info>

## Yang bisa lu kelola

| Service | Produk | Resources | Data sources katalog |
| --- | --- | --- | --- |
| `neolites` | NEO Lite VPS | VM, keypair, snapshot, VM from snapshot, additional disk | products, OS list, change-package options, storage upgrade options, IP availability |
| `neolite-pros` | NEO Lite Pro VPS | VM, keypair, snapshot, additional disk | products, OS list, change-package options, storage upgrade options, IP availability |
| `baremetals` | NEO Metal bare-metal | server, keypair, additional IP, IP assignment, elastic storage | products, rebuild OS list, OpenVPN config |
| `neo-gpus` | NEO GPU | instance, keypair | products, console access, monitoring graph |
| `object-storages` | NEO Object Storage | instance, bucket, credential, object | instances, buckets, credentials |

Masing-masing provider punya **20 resources** dan **19 data sources / functions** buat lima API group ini. Produk yang gak punya public API (NEO Virtual Compute, NEO Kubernetes, NEO DNS, web hosting, GIO Private, GIO Enterprise Cloud, NEO Backup) di luar scope.
