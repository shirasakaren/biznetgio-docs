---
title: "NEO Lite (Pulumi)"
description: "Resource dan function Pulumi buat VPS NEO Lite"
---

Resource NEO Lite di bawah package `biznetgio` (API group `/neolites`). Alur biasa ngerangkai function katalog ke create: `neoliteProducts` → `neoliteOsList` → `NeoliteKeypair` → `NeoliteVm`.

<Info>
  Setiap create/upgrade bikin **order berbayar beneran**. Baca [panduan billing](/guides/billing) buat nilai `cycle` dan semantics `payWithCreditCard`.
</Info>

                return err

                VmName:            pulumi.String("neo-lite-1"),
                ProductId:         pulumi.Int(products.Products[0].ProductId),

                KeypairId:         keypair.KeypairId,

                // MigrateToPro: pulumi.String("12345"),
                // DiskSize:   pulumi.Int(100),
            })

            }

            ctx.Export("vmStatus", vm.Status)

                    .productId(products.applyValue(p -> p.products().get(0).productId()))
                    .selectOs(osList.applyValue(o -> o.oss().get(0).name()))
                    .keypairId(keypair.keypairId())
                    .cycle("m")

                    // .powerState("stop")
                    // .rebuildOs("ubuntu-22")
                    // .migrateToPro("12345")
                    // .diskSize(100)
                    .build());

            ctx.export("vmStatus", vm.status());
        }
    }

| Input | Type | Required | Notes |
| --- | --- | --- | --- |
| `sshAndConsoleUser` | string | yes | di-set pas create |
| `consolePassword` | string, secret | yes | write-only: gak pernah di-fetch ulang dari API |
| `productId` | int64 | yes | dari `neoliteProducts`; ganti = trigger change-package |
| `selectOs` | string | yes | dari `neoliteOsList`; ganti OS = rebuild |
| `keypairId` | int64 | yes | dari `NeoliteKeypair`; ganti = trigger change-keypair |
| `cycle` | string | yes | `m a q s b t p4 p5` |
| `vmName` | string | no | default `server-name`; bisa di-update via change-vm-name |
| `description` | string | no | default `""` |
| `payWithCreditCard` | bool | no | default `true`; `false` = invoice gak dibayar |
| `promocode` | string | no | default `""` |
| `powerState` | string | no | `start` / `stop` / `suspend` / `resume` / `shutdown`; API dipanggil cuma pas berubah |
| `rebuildOs` | string | no | one-shot reinstall OS (destructive) |
| `migrateToPro` | string | no | one-shot migrasi; value = `productId` NEO Lite Pro |
| `diskSize` | int64 | no | target GB absolut, cuma bisa naik |

Import pake `pulumi import biznetgio:index:NeoliteVm demo-vm <account_id>`.
