title: "NEO GPU (Pulumi)"

NEO GPU nyewain instance NVIDIA H200 (`/neo-gpus` API group), ditagih per cycle subscription atau on-demand (per jam). Harus set tepat satu billing mode - kalau nggak, validation gagal.

<Info>
  Setiap create bikin **order berbayar beneran**. Instance on-demand numpuk biaya per jam sampe di-delete.
</Info>

| Input | Type | Required | Notes |
| --- | --- | --- | --- |
| `productId` | int64 | yes | dari `gpuProducts` |
| `selectOs` | string | yes | dari katalog select-OS produk |
| `keypairId` | int64 | yes | dari `GpuKeypair` |
| `sshAndConsoleUser` | string | yes | |
| `consolePassword` | string, secret | yes | |
| `serviceName` | string | no | create-only |
| `promocode` | string | no | |
| `payWithCreditCard` | bool | no | default `true` |
| `subscription` | object | one-of | `{ cycle: "m" \| "a" }` |
| `onDemand` | object | one-of | `{ additionalHours?: number }` default 0 |
| `rebuildTrigger` | string | no | one-shot reinstall OS (destructive) |
| `reserveAdditionalHoursTrigger` | string | no | one-shot: reserve additional hour(s) |

Outputs: `status`, `orderId`, `raw` (secret, di-redact). Import pake numeric account id.

## Functions

### `biznetgio:index:gpuProducts`

Gak ada argument. Return `products`: `productId`, `name`, `description`, `categoryName`, `flavors` (`flavorId`, `name`, `raw`), `raw` (secret).

### `biznetgio:index:gpuConsole`

Argument `accountId` (string). Return `url` (secret) dan `raw` (secret). **Side-effecting:** tiap call bikin session console one-time baru - jangan dipake di dalam plan diffing.

### `biznetgio:index:gpuGraph`

Arguments `accountId` (string), `timeframe` (optional, default `hour`; `hour` / `day` / `week` / `month` / `year`). Return `graph` dan `raw` (secret) dari `GET /neo-gpus/accounts/{id}/graph-monitor`.
