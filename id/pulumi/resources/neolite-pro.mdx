NEO Lite Pro itu tier VPS premium (`/neolite-pros` API group). Set resourcenya mirip NEO Lite dengan pool keypair, snapshot, dan disk sendiri, plus gak ada `migrateToPro` (Pro itu *tujuan* migrasi).

<Info>
  Setiap create/upgrade bikin **order berbayar beneran**. Baca [panduan billing](/guides/billing) buat nilai `cycle` dan semantics `payWithCreditCard`.
</Info>

Input identik sama [`NeoliteVm`](/pulumi/resources/neolite#biznetgioindexneolitevm) minus `migrateToPro`:

| Input | Type | Required | Notes |
| --- | --- | --- | --- |
| `sshAndConsoleUser` | string | yes | |
| `consolePassword` | string, secret | yes | write-only |
| `productId` | int64 | yes | dari `neoliteProProducts`; ganti = trigger change-package |
| `selectOs` | string | yes | dari `neoliteProOsList` |
| `keypairId` | int64 | yes | dari `NeoliteProKeypair`; ganti = trigger change-keypair |
| `cycle` | string | yes | `m a q s b t p4 p5` |
| `vmName` | string | no | default `server-name`; bisa di-update |
| `description` | string | no | default `""` |
| `payWithCreditCard` | bool | no | default `true` |
| `promocode` | string | no | default `""` |
| `powerState` | string | no | `start` / `stop` / `suspend` / `resume` / `shutdown` |
| `rebuildOs` | string | no | one-shot reinstall (destructive) |
| `diskSize` | int64 | no | target GB absolut, cuma bisa naik |

Outputs identik sama `NeoliteVm` (termasuk `lastInvoice` dan `raw` di-redact). Import pake numeric account id.

## Functions

Semua lima nge-mirror function NEO Lite ke `/neolite-pros`:

### `biznetgio:index:neoliteProProducts`

Gak ada argument. Struktur nested sama kayak `neoliteProducts` (`options`, `billing`, `components`, `prices`).

### `biznetgio:index:neoliteProOsList`

Argument `productId`; return `oss` (`vmid`, `node`, `name`, `maxmem`, `maxcpu`).

### `biznetgio:index:neoliteProChangePackageOptions`

Argument `accountId`; return `raw` (secret).

### `biznetgio:index:neoliteProStorageUpgradeOptions`

Argument `accountId`; return `raw` (secret).

### `biznetgio:index:neoliteProIPAvailability`

Argument `productId`; return `available` (bool).
