---
title: "Importing (Terraform)"
description: "Bring existing Biznet GIO resources into Terraform state"
---

Every resource supports `terraform import`. Most use the numeric account id directly; composite resources use a `:`-separated id.

## Import

```bash
terraform import biznetgio_neolite_vm.main 12345
```

After importing, Terraform reads the resource and refreshes all computed attributes. Required inputs must match the live resource — run `terraform plan` and fix any diffs.

## ID formats

| Resource | Import ID |
| --- | --- |
| `biznetgio_neolite_vm` | `<account_id>` |
| `biznetgio_neolite_keypair` | `<keypair_id>` |
| `biznetgio_neolite_snapshot` | `<snapshot account_id>` |
| `biznetgio_neolite_vm_from_snapshot` | `<restored VM account_id>` |
| `biznetgio_neolite_disk` | `<disk account_id>` |
| `biznetgio_neolite_pro_vm` | `<account_id>` |
| `biznetgio_neolite_pro_keypair` | `<keypair_id>` |
| `biznetgio_neolite_pro_snapshot` | `<snapshot account_id>` |
| `biznetgio_neolite_pro_disk` | `<disk account_id>` |
| `biznetgio_baremetal` | `<account_id>` |
| `biznetgio_baremetal_keypair` | `<keypair_id>` |
| `biznetgio_baremetal_additional_ip` | `<account_id>` |
| `biznetgio_baremetal_additional_ip_assignment` | `<metal_account_id>:<additional_ip_id>` |
| `biznetgio_baremetal_elastic_storage` | `<storage account_id>` |
| `biznetgio_gpu_instance` | `<account_id>` |
| `biznetgio_gpu_keypair` | `<keypair_id>` |
| `biznetgio_object_storage` | `<account_id>` |
| `biznetgio_object_storage_bucket` | `<account_id>:<bucket_name>` |
| `biznetgio_object_storage_credential` | `<account_id>:<access_key>` (literal or 16-hex hashed form) |
| `biznetgio_object_storage_object` | `<account_id>:<bucket>:<key>` |

<Note>
  Keypair ids are not interchangeable across services — a NEO Lite keypair id imports into `biznetgio_neolite_keypair` only.
</Note>

## Composite id examples

```bash
# additional IP assignment: server 12345 + additional ip 67890
terraform import biznetgio_baremetal_additional_ip_assignment.main 12345:67890

# bucket inside instance 12345
terraform import biznetgio_object_storage_bucket.assets 12345:my-assets

# credential: access key given literally
terraform import biznetgio_object_storage_credential.main 12345:ABCDEFGHIJKLMNOP

# object inside bucket my-assets
terraform import biznetgio_object_storage_object.index 12345:my-assets:site/index.html
```

<Warning>
  Importing a credential stores the **hashed** form of the access key in the id (`<account_id>:<sha256(access_key)>[:16]`) — the plaintext key is never written to state.
</Warning>
